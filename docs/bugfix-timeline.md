## BUG-20260826-03 · 整书笔记切换图书后回跳（v0.2.4）

- **状态**：已定位、已修改、v0.2.4 构建通过，待用户验收。
- **现象**：从阅读器进入笔记后，点击其他书籍会迅速跳回原书。
- **根因证据**：`NotesWorkspace` 的 effect 依赖 `[books, initialBookId, selectedId]`，每次用户选书后都执行 `setSelectedId(initialBookId)`；并且异步刷新没有请求有效性校验。
- **修复**：由 `App.notesBookId` 唯一控制当前选择；书库刷新仅对已消失书籍回退。加载请求序号和选择版本阻止过期读写回调覆盖新书。后台更新保留本地草稿、不替换编辑区；切书前提示未保存内容，保存中暂禁编辑。
- **影响文件**：`src/App.tsx`。用例：NOTE-03～06。
- **验证**：2026-08-26 重建成功，TypeScript/Vite、Rust release 与 NSIS 打包通过。未运行测试、未启动程序，待用户验收。

## BUG-20260826-01 · 分页后自动回跳（v0.2.3）

- **反馈**：上一页后立刻跳回来，或翻页后发生意外跳页。
- **状态**：已定位、已修改、v0.2.3 构建通过，待用户验收。
- **代码证据**：`src/EpubReader.tsx` 中 `relocated` 在700ms后保存；`src-tauri/src/lib.rs` 每900ms检测目录变化；`src/App.tsx` 再延迟350ms读取书库并更新 `activeBook`；旧版阅读器 `[book.cfi]` effect 只要 CFI 不同就调用 `display()`。
- **根因**：本机保存回流与远程同步被混作导航指令。页面已经移动，但延迟到达的书库快照仍包含旧位置，形成“本地翻页→旧快照→再次定位”的反馈回路。
- **修复**：
  1. Rust 从进度 JSON 的设备文件名推导来源，书库响应增加设备 ID 与进度时间；原 JSON 文件结构无需迁移。
  2. 替换仅监听 CFI 的跳转逻辑。本机来源、未知来源、已处理时间戳、早于本地导航的快照均不能触发远程定位。
  3. 保留真正更新的其他设备进度自动跳转；搜索/摘录预览期间不跳转。
  4. 翻页按钮、键盘、滚轮统一记录本地导航时间；接受更新远程位置前取消旧的待保存计时器。
- **影响文件**：`src/EpubReader.tsx`、`src/App.tsx`、`src/types.ts`、`src-tauri/src/lib.rs`。
- **回归用例**：READ-01～04、SYNC-01～07，见 [项目功能用例](feature-use-cases.md)。
- **已知边界**：跨设备时间比较依赖设备时钟；来源未知的旧记录仅用于打开时续读，不强制打断会话。
- **验证**：2026-08-26，TypeScript/Vite 与 Rust release 编译通过；NSIS 安装包生成成功。首次打包遇到 exe 短暂占用的标记写入警告，重新执行 `tauri bundle --bundles nsis` 后成功且无该警告。沿用用户要求，未运行测试或启动程序，尚未进行交互验收。
- **产物**：`src-tauri/target/release/bookreader.exe`、`src-tauri/target/release/bundle/nsis/BookReader_0.2.3_x64-setup.exe`；未推送、未发布。
